# TurtleBot4 Sim

## What's here
- `src/turtlebot4_simulator/`: **pulled** from GitHub (official). Don't touch.
- `*.sh` and `drive_circle.py`: **written by Claude**. Short helper scripts.
- `build/ install/ log/`: auto-generated by the build. Ignore.

## Setup (once)
```bash
./install_deps.sh
./build.sh
```

## Run
1. Terminal 1: `./run_sim.sh`
2. In Gazebo, click **●●** to undock (it's slow; wait about 20 s).
3. Terminal 2: `./teleop.sh`, click the terminal, then use **i** forward, **j/l** turn, **k** stop.

## AR markers
1. Start the sim and undock the robot, so it turns around to face the markers.
2. `./markers.sh` adds 3 ArUco markers 2.5 m in front of the robot, then opens the camera view.
   It boxes each marker it sees and prints its id and distance.
   (Edit `MARKERS` in `add_markers.py` to change how many there are or where they go.)

## If it breaks
```bash
pkill -f "gz sim"; pkill -f ros2; pkill -f parameter_bridge
```
Then run again.
